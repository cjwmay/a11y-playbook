# A11y Playbook · 无障碍设计每日一课

每天一条无障碍（a11y）设计课，把 WCAG 条款翻译成设计师语言。
One accessibility design lesson a day — WCAG translated into designer language.

## 课程格式 / Lesson format

每课固定五段式 / Every lesson follows the same five-part format:

1. 📏 规则一句话 / The rule in one sentence
2. ❌✅ 正反例子 / Bad vs good examples
3. 🔍 怎么测 / How to test
4. 🛠️ 一行修复 / The one-line fix
5. 🎙️ 面试怎么讲 / How to talk about it in an interview

## 大纲 / Curriculum

56 天，8 周 / 56 days, 8 weeks:

| 周 / Week | 主题 / Theme |
|---|---|
| 1 | 看得见：颜色与对比 / Being seen: color & contrast |
| 2 | 读得懂：结构与缩放 / Being understood: structure & scaling |
| 3 | 键盘可达 / Keyboard access |
| 4 | 手势与动效 / Gestures & motion |
| 5 | 表单 / Forms |
| 6 | 导航与可理解 / Navigation & understandability |
| 7 | ARIA / ARIA |
| 8 | 实战收官 / Putting it into practice |

目标：攒出一套能写进作品集、讲给面试官的完整无障碍 playbook。
Goal: a complete, portfolio-ready accessibility playbook in 56 days.
